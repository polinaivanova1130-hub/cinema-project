# Информационная система управления кинотеатром

Учебный проект по дисциплине «Программная инженерия»  
Лабораторная работа № 1

**Тема**: Информационная система управления кинотеатром  
**Студенты**: Маркарян Л.А., Фриева С.Т., Иванова П.Е.  
**Группа**: 3 курс, 09.03.03 «Прикладная информатика»

## Цель лабораторной работы
Формализовать задачу разработки информационной системы управления кинотеатром, определить заинтересованные стороны и роли пользователей, сформировать функциональные и нефункциональные требования, построить матрицу трассируемости, определить риски и вопросы для уточнения требований.
