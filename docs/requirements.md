# Требования к системе

## Роли пользователей и их потребности

### Посетитель
- просматривать список доступных фильмов;
- просматривать расписание сеансов;
- видеть свободные и занятые места;
- выбирать подходящее место.

### Кассир
- просматривать расписание сеансов;
- видеть свободные места;
- оформлять продажу билетов;
- отменять билеты в допустимый период.

### Администратор
- добавлять, изменять и удалять фильмы;
- управлять кинозалами;
- создавать и изменять расписание;
- предотвращать конфликтующие сеансы.

### Контролёр
- сканировать QR-код билета;
- проверять статус билета;
- видеть информацию о фильме, сеансе, зале и месте;
- предотвращать повторное использование билета.

## Функциональные требования

| ID    | Функциональное требование |
|-------|---------------------------|
| FR-01 | Система должна предоставлять посетителю возможность просматривать список фильмов, доступных для просмотра. |
| FR-02 | Система должна отображать название, описание, жанр, продолжительность и возрастное ограничение фильма. |
| FR-03 | Посетитель должен иметь возможность просматривать расписание сеансов выбранного фильма. |
| FR-04 | Система должна отображать для каждого сеанса дату, время начала, зал и стоимость билета. |
| FR-05 | Система должна отображать схему мест выбранного сеанса с указанием занятых и свободных мест. |
| FR-06 | Посетитель должен иметь возможность выбрать свободное место на выбранный сеанс. |
| FR-07 | Кассир должен иметь возможность оформить продажу билета на выбранный сеанс и место. |
| FR-08 | Система должна запрещать продажу уже занятого места. |
| FR-09 | Система должна сохранять информацию о проданных билетах. |
| FR-10 | Кассир должен иметь возможность отменить продажу билета до начала соответствующего сеанса. |
| FR-11 | Администратор должен иметь возможность добавлять новые фильмы в систему. |
| FR-12 | Администратор должен иметь возможность изменять и удалять информацию о фильмах. |
| FR-13 | Администратор должен иметь возможность добавлять и изменять информацию о кинозалах. |
| FR-14 | Администратор должен иметь возможность создавать, изменять и удалять сеансы. |
| FR-15 | Система должна запрещать создание сеансов в одном зале, если их временные интервалы пересекаются. |
| FR-16 | Контролёр должен иметь возможность отсканировать QR-код билета. |
| FR-17 | Система должна проверять существование билета и соответствие его данных выбранному сеансу. |
| FR-18 | При проверке билета система должна отображать фильм, дату, время, зал и место, указанные в билете. |
| FR-19 | Система должна определять статус билета: действителен, использован, отменён или недействителен. |
| FR-20 | Система должна запрещать повторное использование уже проверенного билета. |
| FR-21 | Система должна подтверждать возможность прохода посетителя при успешной проверке билета. |
| FR-22 | Система должна отображать контролёру текущую заполненность выбранного зала. |
| FR-23 | Система должна обновлять информацию о занятых и свободных местах после успешной проверки билета. |
| FR-24 | Контролёр должен иметь возможность просматривать количество занятых и свободных мест для текущего сеанса. |

## Нефункциональные требования

**NFR-01. Производительность**  
Время ответа системы на основные операции просмотра фильмов, расписания и мест не должно превышать 2 секунд при нагрузке до 100 одновременно работающих пользователей.

**NFR-02. Безопасность**  
Система должна предоставлять доступ к функциям управления фильмами, залами и расписанием только пользователю с ролью администратора.

**NFR-03. Разграничение прав**  
Система должна предоставлять функции оформления и отмены билетов только пользователю с ролью кассира.

**NFR-04. Надёжность**  
Система не должна допускать одновременную продажу одного места на один сеанс нескольким покупателям.

**NFR-05. Доступность**  
Система должна быть доступна не менее 99 % времени в течение календарного месяца, за исключением заранее запланированных технических работ.

**NFR-06. Удобство использования**  
Пользователь должен иметь возможность перейти от выбора фильма к просмотру доступных сеансов не более чем за три последовательных действия.

**NFR-07. Поддерживаемость**  
Исходный код системы должен быть разделён на отдельные компоненты, отвечающие за работу с фильмами, сеансами, залами и билетами.
