# Назначение и цели системы

Информационная система управления кинотеатром предназначена для автоматизации основных процессов работы кинотеатра, связанных с управлением фильмами, кинозалами, расписанием сеансов и продажей билетов. Система должна обеспечить централизованное хранение информации, предоставление актуального расписания и контроль доступности мест.

## Основные пользователи
- **Посетитель** — просматривает фильмы, расписание и доступные места.
- **Кассир** — оформляет и отменяет продажу билетов.
- **Администратор** — управляет фильмами, кинозалами и сеансами.
- **Контролёр** — проверяет билеты по QR-коду.

## Основные цели проекта
- Снижение количества ошибок при формировании расписания и продаже билетов.
- Предотвращение двойной продажи одного места.
- Сокращение времени обработки операций.
- Обеспечение контроля использования билетов.

## Ограничения MVP
Система предназначена для использования сотрудниками и посетителями одного кинотеатра.  
В рамках MVP **не** предусматриваются:
- интеграции с внешними платёжными системами;
- онлайн-кинотеатры;
- внешние сервисы бронирования.

Реализация выполняется как учебный проект с ограниченным количеством пользователей и залов.
