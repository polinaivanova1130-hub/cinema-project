# Глоссарий

| Термин       | Определение |
|--------------|-------------|
| Фильм        | Кинофильм, доступный для показа в кинотеатре |
| Кинозал      | Помещение кинотеатра, оборудованное для показа фильмов и имеющее набор посадочных мест |
| Сеанс        | Запланированный показ определённого фильма в конкретном зале и в определённое время |
| Место        | Конкретное посадочное место в кинозале |
| Билет        | Электронная запись, подтверждающая право посетителя занять определённое место на выбранном сеансе |
| QR-код       | Двумерный код, содержащий идентификатор билета и используемый для его проверки |
| Статус билета| Текущее состояние билета: действителен, использован, отменён или недействителен |
| Репертуар    | Перечень фильмов, доступных для просмотра в кинотеатре |
